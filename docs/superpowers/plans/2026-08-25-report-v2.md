## Task A: Sessions detection (pure, TDD)

**Files:** Create `src/analysis/sessions.ts`; Test `tests/analysis/sessions.test.ts`

Contract:
```ts
export interface Session { startT: number; endT: number; durationMs: number; eventCount: number; }
export interface Break { afterSessionIndex: number; startT: number; durationMs: number; }
export interface SessionBreakdown { sessions: Session[]; breaks: Break[]; totalActiveMs: number; }
export function detectSessions(events: EditEvent[], idleThresholdMs: number): SessionBreakdown;
```
Rules: events sorted by `t`. A gap `> idleThresholdMs` between consecutive events ends a session and records a break. A single event forms a session of duration 0. `totalActiveMs` = sum of session durations. Empty input → all empty, 0.

Tests must cover: empty log; one event; two sessions split by a big gap (assert session boundaries, break start/duration, totalActiveMs).

Steps: failing test → run (fail) → implement → run (pass) → full `npx vitest run` → commit `feat: detect editing sessions and breaks from event log`.

## Task B: Timeline series with pause compression (pure, TDD)

**Files:** Create `src/analysis/timeline.ts`; Test `tests/analysis/timeline.test.ts`

Contract:
```ts
export interface TimelinePoint {
  t: number;         // real epoch ms of bucket end
  activeT: number;   // ms on the compressed (active-time) x-axis
  docLen: number;    // document length at bucket end
  added: number;     // chars added in bucket
  removed: number;   // chars removed in bucket
  wpm: number;       // (typed chars in bucket / 5) / bucket minutes, 0 if empty
}
export interface PauseMarker { activeT: number; t: number; durationMs: number; }
export interface Timeline { points: TimelinePoint[]; pauses: PauseMarker[]; }
export function computeTimeline(events: EditEvent[], opts: { idleThresholdMs: number; targetPoints?: number }): Timeline;
```
Rules: x-axis is cumulative **active** time — inter-event gaps are capped at `idleThresholdMs`; when a gap is capped, emit a `PauseMarker` at that `activeT` with the real `durationMs`. Bucket events into at most `targetPoints` (default 120) buckets of equal active-time width; each bucket accumulates added (`len` of insert events), removed (`removed.length`), typed chars for wpm, and ends with the running `docLen` (track by applying length deltas: `text.length - removed.length`). Empty input → empty arrays.

Tests must cover: steady typing produces monotonically increasing `docLen` and correct final length; a paste bucket shows a large `added`; a long gap produces exactly one `PauseMarker` with the real duration while `activeT` stays compressed (last point's `activeT` ≪ real span); deletion decreases `docLen`.

Steps: failing tests → fail → implement → pass → full suite → commit `feat: compute chart timeline with pause compression`.
